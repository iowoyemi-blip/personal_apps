# Counter Web App

Standalone HTML version of Isaac's Counter app.

## What It Does

- Saves up to 12 named counters in the browser.
- Adds and subtracts by each counter's step size.
- Supports editing, resetting, and deleting counters.
- Uses local browser storage only.
- Has no ads, accounts, server, build step, or external dependencies.

## Files

- `index.html` is the complete app.

## GitHub Pages

For a simple GitHub Pages deployment, use this folder as the site source or copy `index.html` to the root of a Pages-enabled repo.

Counts are saved per browser/device. They do not sync between devices.
