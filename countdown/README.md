# Countdown Web App

Standalone HTML version of Isaac's Countdown app.

## What It Does

- Saves up to four named countdowns in the browser.
- Shows days, hours, minutes, and seconds remaining.
- Updates every second while the app is open.
- Supports adding, editing, deleting, exporting, and importing countdowns.
- Uses local browser storage only.
- Has no accounts, ads, server, build step, or external dependencies.

## Files

- `index.html` is the complete app.
- `manifest.webmanifest`, `sw.js`, and icon files support Home Screen use and offline loading.
