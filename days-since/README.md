# Days Since

Standalone HTML app for tracking how many days have passed since selected dates.

## What It Does

- Saves multiple named date cards in the browser.
- Calculates days since each selected date.
- Updates automatically while the page is open.
- Uses local browser storage only.
- Has no ads, accounts, server, build step, or external dependencies.

## Files

- `index.html` is the complete app.

Counts are saved per browser/device. They do not sync between devices.
